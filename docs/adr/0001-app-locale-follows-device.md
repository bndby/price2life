# App Locale follows the device until an explicit language is chosen

Пока пользователь не выбрал русский, английский или упрощённый китайский, App Locale следует языку устройства (при старте и при возврате из фона): `ru*` → русский, `en*` → английский, `zh*` → упрощённый китайский, иначе русский. Явный выбор сразу сохраняется и больше не зависит от системы; пункт «язык системы» снова включает следование устройству. Локаль живёт только в приложении, нативный locale процесса Android не меняем.

**Considered Options**: snapshot языка при первом запуске (отклонено: смена языка Android перестаёт влиять, пока человек не зашёл в настройки; существующие установки без ключа выглядели бы как «первый запуск»).
